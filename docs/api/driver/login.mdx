# Driver Login

<Endpoint method="POST" path="/api/v1/driver/auth/login" publicAccess />

Verifies a driver's credentials and starts a session. There are **two possible successful outcomes**,
distinguished by `data.nextAction`:

- **`LOGIN_SUCCESS`** — no session existed, or the existing one was on the same app install. Tokens
  are returned and the driver is signed in.
- **`CONFIRM_DEVICE_SWITCH`** — the driver has an active session on a *different* device. Nothing is
  changed. A confirmation token is returned, and the app must call
  [Confirm Login](/api/driver/confirm-login) to take over the session.

Both outcomes are `200 OK`. Branch on `nextAction`, not on the status code.

## Request body

    { name: 'device_info.os', type: 'string', required: true, description: 'Operating system.', example: '"Android"' },

    { name: 'device_info.manufacturer', type: 'string', required: true, description: 'Device manufacturer.', example: '"Google"' },
    { name: 'device_info.model', type: 'string', required: true, description: 'Device model.', example: '"Pixel 7"' },

  ]}

## Responses

```json title="200 — LOGIN_SUCCESS"
{
  "status": true,
  "status_code": 200,
  "message": "Success",
  "data": {
    "nextAction": "LOGIN_SUCCESS",
    "confirmationToken": null,
    "existingDevice": null,
    "tokens": {
      "accessToken": "eyJhbGciOiJIUzI1NiIs...",
      "refreshToken": "eyJhbGciOiJIUzI1NiIs..."
    },
    "driverInfo": { "id": 42 }
  }
}
```

  "status": true,

    "confirmationToken": "8f3c2a2c-8e2f-4b7c-9f2f-6a2b8c1e2d3f",

<ParamTable
  title="data fields"
  params={[
    { name: 'nextAction', type: 'string', required: true, values: ['LOGIN_SUCCESS', 'CONFIRM_DEVICE_SWITCH'], description: 'Which outcome this is. Branch on it.' },
    { name: 'confirmationToken', type: 'string (uuid) | null', required: false, description: 'Present only on CONFIRM_DEVICE_SWITCH. Single-use, and valid for 2 minutes.' },
    { name: 'existingDevice', type: 'object | null', required: false, description: 'Present only on CONFIRM_DEVICE_SWITCH — the device currently signed in, so the driver can recognise it.' },
    { name: 'existingDevice.name', type: 'string', required: false, description: 'Device name.' },
    { name: 'existingDevice.model', type: 'string', required: false, description: 'Device model.' },
    { name: 'tokens', type: 'object | null', required: false, description: 'Present only on LOGIN_SUCCESS.' },
    { name: 'tokens.accessToken', type: 'string', required: false, description: 'Access JWT, valid 1 hour.' },
    { name: 'tokens.refreshToken', type: 'string', required: false, description: 'Refresh JWT, valid 24 hours.' },
    { name: 'driverInfo', type: 'object | null', required: false, description: 'Returned on both outcomes.' },
    { name: 'driverInfo.id', type: 'integer', required: false, description: 'The driver id.' },
  ]}
/>

:::caution The confirmation token expires in 2 minutes
It is also **single-use** — consumed atomically, so two concurrent confirmations with the same token
cannot both succeed. If the driver takes too long, start again from `/login`.
:::

## Errors

<ErrorTable
  errors={[
    { status: 401, code: 'INVALID_CREDENTIALS', when: <>The email is not registered, or the password does not match. The two cases are deliberately indistinguishable.</> },
    { status: 401, code: 'INVALID_TOKEN', when: <>The driver record disappeared between credential check and session creation.</> },
    { status: 403, code: 'FORBIDDEN', when: <>The driver account is inactive or disabled.</> },
    { status: 422, code: 'VALIDATION_ERROR', when: <>A required field is missing, or <code>email</code> is not a valid address.</> },
