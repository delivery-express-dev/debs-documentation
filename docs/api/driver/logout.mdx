# Driver Logout

<Endpoint method="POST" path="/api/v1/driver/auth/logout" auth="Bearer token" />

Invalidates the caller's session. Because tokens are checked against the session row on every
request, the driver's outstanding access token stops working **immediately** — it does not remain
valid until `exp`.

## Request

No body, no query parameters. The session to end is identified from the access token.

<ParamTable
  title="Headers"
  params={[
    { name: 'Authorization', type: 'string', required: true, description: "Bearer YOUR_TOKEN — the driver's access token.", example: '"Bearer eyJhbGciOiJIUzI1NiIs..."' },
  ]}
/>

## Response

`200 OK`

```json
{
  "status": true,
  "status_code": 200,
  "message": "Success",
  "data": {}
}
```

`data` is always an empty object.

:::note Logout is idempotent
If the token's session is already gone — the driver logged out earlier, or signed in elsewhere and
superseded it — the call still returns `200`. It never reports "already logged out" as an error, so
a client can always call it safely on sign-out.
:::
