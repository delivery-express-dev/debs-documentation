# Issue Item to Driver

<Endpoint
  method="POST"
  path="/api/v1/web-app/drivers/{driver_id}/issued-items"
  auth="Bearer token"
  permission="create-driver_issued_items"
/>

Records that an item has been handed to a driver. Creates a ledger row with `status: "ISSUED"` and a
null `restored_date`.

The catalogue entry's current titles are copied onto the assignment for audit, so the ledger remains
accurate even if the catalogue entry is renamed afterwards.

## Path parameters

<ParamTable
  params={[
    { name: 'driver_id', type: 'integer', required: true, description: 'The driver receiving the item.', example: '7' },
  ]}
/>

## Request body

<ParamTable
  params={[
    { name: 'issued_item_id', type: 'integer', required: true, description: <>The catalogue entry being issued. Must exist and be <code>ACTIVE</code> — a retired entry is rejected. Fetch ids from <a href="/api/operations/issued-items/list-issued-items">List Issued Items</a>.</>, example: '4' },
    { name: 'issue_date', type: 'string (date)', required: true, description: 'When the item was handed over, YYYY-MM-DD.', example: '"2026-02-01"' },
    { name: 'amount', type: 'integer', required: false, description: 'Quantity or monetary amount issued, depending on the category. For a cash float this is the amount; for equipment it is the count.', example: '1' },
    { name: 'item_code', type: 'string', required: false, description: 'Asset tag or serial number for this specific item, at most 150 characters.', example: '"HLM-0099"' },
  ]}
/>

:::note `status` and `restored_date` are not accepted
A new assignment is always `ISSUED` with a null `restored_date`. Returning the item is a separate
call — see [Restore Item](/api/operations/driver-issued-items/restore-driver-issued-item).
:::

## Request example

<Tabs groupId="lang">
<TabItem value="curl" label="cURL">

```bash
curl --request POST \
  --url 'https://sandboxapi.allowmena.com/api/v1/web-app/drivers/7/issued-items' \
  --header 'Authorization: Bearer YOUR_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{
    "issued_item_id": 4,
    "issue_date": "2026-02-01",
    "amount": 1,
    "item_code": "HLM-0099"
  }'
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.post(
    "https://sandboxapi.allowmena.com/api/v1/web-app/drivers/7/issued-items",
    headers={
        "Authorization": f"Bearer {os.environ['ALLOW_TOKEN']}",
        "Content-Type": "application/json",
    },
    json={
        "issued_item_id": 4,
        "issue_date": "2026-02-01",
        "amount": 1,
        "item_code": "HLM-0099",
    },
    timeout=30,
)
response.raise_for_status()

# Keep the assignment id — it is what you restore against later.
print(response.json()["data"]["id"])
```

## Response

`201 Created`

```json
{
  "status": true,
  "status_code": 201,
  "message": "Driver issued item created successfully",
  "data": {
    "id": 331,
    "issued_item_id": 4,
    "issued_item_title_en": "Safety helmet",
    "issued_item_title_ar": "خوذة أمان",
    "amount": 1,
    "item_code": "HLM-0099",
    "issue_date": "2026-02-01",
    "status": "ISSUED",
    "restored_date": null,
    "created_at": "2026-02-01 08:31:44"
  }
}
```

Store `data.id` — it is the `assignment_id` you need to mark the item returned.

## Errors

<ErrorTable
  errors={[
    { status: 400, code: 'BAD_REQUEST', when: <><code>issued_item_id does not exist</code> — no catalogue entry with that id.</> },
    { status: 400, code: 'BAD_REQUEST', when: <><code>Issued item is inactive</code> — the catalogue entry exists but has been retired.</> },
    { status: 401, code: 'TOKEN_MISSING', when: <>No <code>Authorization</code> header.</> },
    { status: 403, code: 'FORBIDDEN', when: <>The token lacks <code>create-driver_issued_items</code>.</> },
    { status: 404, code: 'NOT_FOUND', when: <><code>Driver not found</code> — no driver with that id.</> },
    { status: 422, code: 'VALIDATION_ERROR', when: <>A required field is missing, <code>issue_date</code> is not a valid date, or <code>item_code</code> exceeds 150 characters.</> },
    { status: 500, code: 'INTERNAL_SERVER_ERROR', when: <>Unhandled server error.</> },
  ]}
/>
