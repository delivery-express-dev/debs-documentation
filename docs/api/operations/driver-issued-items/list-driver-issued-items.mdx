# List Driver Issued Items

<Endpoint
  method="GET"
  path="/api/v1/web-app/drivers/{driver_id}/issued-items"
  auth="Bearer token"
  permission="read-driver_issued_items"
/>

Returns the ledger of what has been issued to one driver — both what they currently hold (`ISSUED`)
and what they have returned (`RESTORED`).

Each row carries the item's titles **as they were at the time of issue**, snapshotted onto the
assignment. Renaming a catalogue entry later does not rewrite history, and the portal does not need
a second call to the catalogue to render the ledger.

## Path parameters

<ParamTable
  params={[
    { name: 'driver_id', type: 'integer', required: true, description: 'The driver whose ledger to read. Must exist, or the request returns 404.', example: '7' },
  ]}
/>

## Query parameters

<ParamTable
  params={[
    { name: 'page', type: 'integer', required: false, default: '1', description: 'Page number, starting at 1.', example: '2' },
    { name: 'per_page', type: 'integer', required: false, description: 'Page size, between 1 and 100.', example: '25' },
  ]}
/>

There is no status filter — the ledger returns both issued and restored rows.

## Request example

<Tabs groupId="lang">
<TabItem value="curl" label="cURL">

```bash
curl --request GET \
  --url 'https://sandboxapi.allowmena.com/api/v1/web-app/drivers/7/issued-items?per_page=25' \
  --header 'Authorization: Bearer YOUR_TOKEN'
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.get(
    "https://sandboxapi.allowmena.com/api/v1/web-app/drivers/7/issued-items",
    headers={"Authorization": f"Bearer {os.environ['ALLOW_TOKEN']}"},
    params={"per_page": 25},
    timeout=30,
)
response.raise_for_status()

still_held = [row for row in response.json()["data"] if row["status"] == "ISSUED"]
for row in still_held:
    print(row["id"], row["issued_item_title_en"], row["issue_date"])
```

</TabItem>
<TabItem value="js" label="JavaScript">

```javascript
const url = new URL(
  'https://sandboxapi.allowmena.com/api/v1/web-app/drivers/7/issued-items',
);
url.searchParams.set('per_page', '25');

const response = await fetch(url, {
  headers: { Authorization: `Bearer ${process.env.ALLOW_TOKEN}` },
});

const stillHeld = (await response.json()).data.filter((row) => row.status === 'ISSUED');
for (const row of stillHeld) {
  console.log(row.id, row.issued_item_title_en, row.issue_date);
}
```

</TabItem>
