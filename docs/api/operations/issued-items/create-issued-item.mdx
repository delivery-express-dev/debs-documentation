# Create Issued Item

<Endpoint
  method="POST"
  path="/api/v1/web-app/issued-items"
  auth="Bearer token"
  permission="create-issued_items"
/>

Adds an entry to the catalogue of items that can be issued to drivers. New entries are always
created `ACTIVE`.

## Request body

<ParamTable
  params={[
    { name: 'category_code', type: 'string', required: true, values: ['HLMT001', 'TSRT001', 'PNTS001', 'JCKT001', 'PHNE001', 'CASH001', 'HBG001'], description: <>Item category. Must match an existing category — fetch the list from <a href="/api/operations/reference-data#item-categories">Item Categories</a>. At most 20 characters.</>, example: '"HLMT001"' },
    { name: 'title_en', type: 'string', required: true, description: 'English title, at most 150 characters.', example: '"Safety helmet"' },
    { name: 'title_ar', type: 'string', required: true, description: 'Arabic title, at most 150 characters.', example: '"خوذة أمان"' },
  ]}
/>

:::note `status` is not accepted on create
New entries are always `ACTIVE`. A `status` in the payload is ignored. To retire an entry, patch it
to `INACTIVE` — see [Update Issued Item](/api/operations/issued-items/update-issued-item).
:::

## Request example

<Tabs groupId="lang">
<TabItem value="curl" label="cURL">

```bash
curl --request POST \
  --url 'https://sandboxapi.allowmena.com/api/v1/web-app/issued-items' \
  --header 'Authorization: Bearer YOUR_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{
    "category_code": "HLMT001",
    "title_en": "Safety helmet",
    "title_ar": "خوذة أمان"
  }'
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.post(
    "https://sandboxapi.allowmena.com/api/v1/web-app/issued-items",
    headers={
        "Authorization": f"Bearer {os.environ['ALLOW_TOKEN']}",
        "Content-Type": "application/json",
    },
    json={
        "category_code": "HLMT001",
        "title_en": "Safety helmet",
        "title_ar": "خوذة أمان",
    },
    timeout=30,
)
response.raise_for_status()

print(response.json()["data"]["id"])
```

</TabItem>
<TabItem value="js" label="JavaScript">
