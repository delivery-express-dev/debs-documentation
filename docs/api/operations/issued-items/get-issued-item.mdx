# Get Issued Item

<Endpoint
  method="GET"
  path="/api/v1/web-app/issued-items/{issued_item_id}"
  auth="Bearer token"
  permission="read-issued_items"
/>

Returns a single catalogue entry by id.

## Path parameters

<ParamTable
  params={[
    { name: 'issued_item_id', type: 'integer', required: true, description: 'The catalogue entry to retrieve.', example: '4' },
  ]}
/>

## Request example

<Tabs groupId="lang">
<TabItem value="curl" label="cURL">

```bash
curl --request GET \
  --url 'https://sandboxapi.allowmena.com/api/v1/web-app/issued-items/4' \
  --header 'Authorization: Bearer YOUR_TOKEN'
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.get(
    "https://sandboxapi.allowmena.com/api/v1/web-app/issued-items/4",
    headers={"Authorization": f"Bearer {os.environ['ALLOW_TOKEN']}"},
    timeout=30,
)
response.raise_for_status()

print(response.json()["data"]["title_en"])
```

</TabItem>
<TabItem value="js" label="JavaScript">

```javascript
const response = await fetch(
  'https://sandboxapi.allowmena.com/api/v1/web-app/issued-items/4',
  { headers: { Authorization: `Bearer ${process.env.ALLOW_TOKEN}` } },
);

console.log((await response.json()).data.title_en);
```

</TabItem>
</Tabs>

## Response

`200 OK`

```json
{
  "status": true,
  "status_code": 200,
  "message": "Issued item fetched successfully",
  "data": {
    "id": 4,
    "category_code": "HLMT001",
    "title_en": "Safety helmet",
    "title_ar": "خوذة أمان",
    "status": "ACTIVE",
    "created_at": "2026-01-14 09:02:11",
    "updated_at": "2026-03-02 14:20:55"
  }
}
```

Field meanings are as described on
[List Issued Items](/api/operations/issued-items/list-issued-items#response).

## Errors

<ErrorTable
  errors={[
    { status: 401, code: 'TOKEN_MISSING', when: <>No <code>Authorization</code> header.</> },

    { status: 404, code: 'NOT_FOUND', when: <><code>Issued item not found</code> — no catalogue entry with that id.</> },
    { status: 422, code: 'VALIDATION_ERROR', when: <><code>issued_item_id</code> is not an integer.</> },

  ]}
