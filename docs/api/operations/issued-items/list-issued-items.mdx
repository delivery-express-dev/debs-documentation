# List Issued Items

<Endpoint
  method="GET"
  path="/api/v1/web-app/issued-items"
  auth="Bearer token"
  permission="read-issued_items"
/>

Returns the catalogue of items that can be issued to drivers — helmets, jackets, phones, cash floats
and so on. This is the master list; what an individual driver actually holds lives in the
[driver issued-items ledger](/api/operations/driver-issued-items/list-driver-issued-items).

## Query parameters

<ParamTable
  params={[
    { name: 'search', type: 'string', required: false, description: 'Case-insensitive substring match against title_en OR title_ar — a match in either title returns the row.', example: 'helmet' },
    { name: 'status', type: 'string', required: false, values: ['ACTIVE', 'INACTIVE'], description: 'Restrict to catalogue entries in this state.', example: 'ACTIVE' },
    { name: 'page', type: 'integer', required: false, default: '1', description: 'Page number, starting at 1.', example: '2' },
    { name: 'per_page', type: 'integer', required: false, description: 'Page size, between 1 and 100.', example: '25' },
  ]}
/>

:::note This module paginates by page number
`page` and `per_page` here, not `limit`/`offset` as on the supplier and report endpoints. The
response envelope is the same in both cases. See [Pagination](/concepts/pagination).
:::

## Request example

<Tabs groupId="lang">
<TabItem value="curl" label="cURL">

```bash
curl --request GET \
  --url 'https://sandboxapi.allowmena.com/api/v1/web-app/issued-items?status=ACTIVE&per_page=25' \
  --header 'Authorization: Bearer YOUR_TOKEN'
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.get(
    "https://sandboxapi.allowmena.com/api/v1/web-app/issued-items",
    headers={"Authorization": f"Bearer {os.environ['ALLOW_TOKEN']}"},
    params={"status": "ACTIVE", "per_page": 25},
    timeout=30,
)
response.raise_for_status()

for item in response.json()["data"]:
    print(item["id"], item["category_code"], item["title_en"])
```

</TabItem>
<TabItem value="js" label="JavaScript">

```javascript
const url = new URL('https://sandboxapi.allowmena.com/api/v1/web-app/issued-items');
url.searchParams.set('status', 'ACTIVE');
url.searchParams.set('per_page', '25');

const response = await fetch(url, {
  headers: { Authorization: `Bearer ${process.env.ALLOW_TOKEN}` },
});

for (const item of (await response.json()).data) {
  console.log(item.id, item.category_code, item.title_en);
}
```

</TabItem>
</Tabs>
