# Get Driver Attendance Report

<Endpoint
  method="GET"
  path="/api/v1/web-app/reports/driver-attendance"
  auth="Bearer token"
  permission="read-driver_attendance_report"
/>

Returns a per-shift attendance record for **one** driver over a date range: when they were scheduled,
when they actually checked in and out, how late they were, how long they spent on break, and how many
orders they delivered or had cancelled.

Use it for payroll, shift compliance and absence tracking.

## Query parameters

All three are required. This endpoint is **not paginated** — it returns every row in the range.

<ParamTable
  params={[
    { name: 'driver_id', type: 'integer', required: true, description: 'The driver to report on. One driver per request.', example: '7' },
    { name: 'start_date', type: 'string (date)', required: true, description: 'Start of the date range, YYYY-MM-DD.', example: '2026-09-01' },
    { name: 'end_date', type: 'string (date)', required: true, description: 'End of the date range, YYYY-MM-DD.', example: '2026-09-10' },
  ]}
/>

:::note `snake_case` parameters here
This endpoint spells its parameters `driver_id`, `start_date` and `end_date`. The
[driver performance report](/api/operations/reports/driver-performance) next door uses `startDate`
and `endDate`. They are not interchangeable.
:::

## Request example

<Tabs groupId="lang">
<TabItem value="curl" label="cURL">

```bash
curl --request GET \
  --url 'https://sandboxapi.allowmena.com/api/v1/web-app/reports/driver-attendance?driver_id=7&start_date=2026-09-01&end_date=2026-09-10' \
  --header 'Authorization: Bearer YOUR_TOKEN'
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.get(
    "https://sandboxapi.allowmena.com/api/v1/web-app/reports/driver-attendance",
    headers={"Authorization": f"Bearer {os.environ['ALLOW_TOKEN']}"},
    params={"driver_id": 7, "start_date": "2026-09-01", "end_date": "2026-09-10"},
    timeout=30,
)
response.raise_for_status()

report = response.json()["data"]
print(report["driver_info"]["name"])
for row in report["rows"]:
    print(row["date"], row["checked_in_at"], row["late_minutes"])
```

</TabItem>
<TabItem value="js" label="JavaScript">

```javascript
const url = new URL(
  'https://sandboxapi.allowmena.com/api/v1/web-app/reports/driver-attendance',
);
url.searchParams.set('driver_id', '7');
url.searchParams.set('start_date', '2026-09-01');
url.searchParams.set('end_date', '2026-09-10');

const response = await fetch(url, {
  headers: { Authorization: `Bearer ${process.env.ALLOW_TOKEN}` },
});

const report = (await response.json()).data;
console.log(report.driver_info.name);
for (const row of report.rows) {
  console.log(row.date, row.checked_in_at, row.late_minutes);
}
```

</TabItem>
</Tabs>

:::note Durations are `HH:MM` strings, not numbers
`break_duration`, `temp_break_duration` and `total_working_hours` are formatted strings. Only
`late_minutes` is a number. Parse accordingly.
:::
