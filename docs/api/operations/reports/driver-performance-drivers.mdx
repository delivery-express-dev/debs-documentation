# List Report Drivers

<Endpoint
  method="GET"
  path="/api/v1/web-app/reports/driver-performance/drivers"
  auth="Bearer token"
  permission="read-driver_performance_report"
/>

Returns a paginated id/name/vehicle-type list of drivers, for populating the driver multiselect on
the [driver performance report](/api/operations/reports/driver-performance).

The list is deliberately **not** restricted to active or enabled drivers: a driver who has since
been offboarded can still have past orders worth filtering by, and excluding them would hide history.

## Query parameters

<ParamTable
  params={[
    { name: 'search', type: 'string', required: false, description: 'Case-insensitive substring match on driver name.', example: 'john' },
    { name: 'limit', type: 'integer', required: false, default: '8', description: 'Page size, between 1 and 200.', example: '50' },
    { name: 'offset', type: 'integer', required: false, default: '0', description: 'Records to skip.', example: '50' },
    { name: 'noPage', type: 'boolean', required: false, default: 'false', description: 'If true, return every driver without pagination — useful for filling the filter in one call.', example: 'true' },
  ]}
/>

## Request example

<Tabs groupId="lang">
<TabItem value="curl" label="cURL">

```bash
curl --request GET \
  --url 'https://sandboxapi.allowmena.com/api/v1/web-app/reports/driver-performance/drivers?search=john&limit=20' \
  --header 'Authorization: Bearer YOUR_TOKEN'
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.get(
    "https://sandboxapi.allowmena.com/api/v1/web-app/reports/driver-performance/drivers",
    headers={"Authorization": f"Bearer {os.environ['ALLOW_TOKEN']}"},
    params={"search": "john", "limit": 20},
    timeout=30,
)
response.raise_for_status()

for driver in response.json()["data"]:
    print(driver["id"], driver["name"], driver["vehicleType"])
```

</TabItem>
<TabItem value="js" label="JavaScript">

```javascript
const url = new URL(
  'https://sandboxapi.allowmena.com/api/v1/web-app/reports/driver-performance/drivers',
);
url.searchParams.set('search', 'john');
url.searchParams.set('limit', '20');

const response = await fetch(url, {
  headers: { Authorization: `Bearer ${process.env.ALLOW_TOKEN}` },
});

for (const driver of (await response.json()).data) {
  console.log(driver.id, driver.name, driver.vehicleType);
}
```
