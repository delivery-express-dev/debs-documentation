# Get Supplier

<Endpoint
  method="GET"
  path="/api/v1/web-app/suppliers/{supplier_id}"
  auth="Bearer token"
  permission={['read-supplier', 'create-supplier', 'update-supplier']}
/>

Returns a single supplier in full: country, business types, logo, status and the owning user account.
This is what the portal's supplier detail and edit screens read — which is why the create and update
permissions also grant access.

## Path parameters

<ParamTable
  params={[
    { name: 'supplier_id', type: 'integer', required: true, description: 'The supplier to retrieve.', example: '12' },
  ]}
/>

## Request example

<Tabs groupId="lang">
<TabItem value="curl" label="cURL">

```bash
curl --request GET \
  --url 'https://sandboxapi.allowmena.com/api/v1/web-app/suppliers/12' \
  --header 'Authorization: Bearer YOUR_TOKEN'
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.get(
    "https://sandboxapi.allowmena.com/api/v1/web-app/suppliers/12",
    headers={"Authorization": f"Bearer {os.environ['ALLOW_TOKEN']}"},
    timeout=30,
)
response.raise_for_status()

supplier = response.json()["data"]
print(supplier["supplierName"], supplier["userDetails"]["email"])
```

</TabItem>
<TabItem value="js" label="JavaScript">

```javascript
const response = await fetch('https://sandboxapi.allowmena.com/api/v1/web-app/suppliers/12', {
  headers: { Authorization: `Bearer ${process.env.ALLOW_TOKEN}` },
});

const supplier = (await response.json()).data;
console.log(supplier.supplierName, supplier.userDetails.email);
```

</TabItem>
</Tabs>
