# Get Delivery Price

<Endpoint method="POST" path="/api/v1/external/order/delivery-price" auth="x-api-key header" />

Quotes the delivery charge for a pickup-to-drop-off route, without creating an order. Use it to show
a customer the delivery fee at checkout before you commit.

The charge is derived from the straight-line distance between the two points, your branch's
configured vehicle type, and your branch's pricing configuration.

:::note Note the singular `order` in the path
This route is `/api/v1/external/**order**/delivery-price`, not `orders`. Every other partner
endpoint uses the plural.
:::

## Request body

Unlike the create endpoints, this takes a **single route**, not an `orders` array.

## Request example

<Tabs groupId="lang">
<TabItem value="curl" label="cURL">

```bash
curl --request POST \
  --url 'https://sandboxapi.allowmena.com/api/v1/external/order/delivery-price' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "pickup": { "latitude": 29.320556, "longitude": 48.037866 },
    "drop-off": { "latitude": 29.376, "longitude": 47.977 }
  }'
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

response = requests.post(
    "https://sandboxapi.allowmena.com/api/v1/external/order/delivery-price",
    headers={"x-api-key": os.environ["ALLOW_API_KEY"], "Content-Type": "application/json"},
    json={
        "pickup": {"latitude": 29.320556, "longitude": 48.037866},
        "drop-off": {"latitude": 29.376, "longitude": 47.977},
    },
    timeout=30,
)

body = response.json()
if not body["status"]:
    raise RuntimeError(f"Quote failed ({response.status_code}): {body['message']}")

print("delivery charge:", body["data"]["delivery_charge"])
```

</TabItem>

### Quoting to an area, from the branch address

```json title="Request body"
{
  "drop-off": { "area": "Jabriya" }
}
```

## Response

`200 OK`

```json
{
  "status": true,
  "message": "Success",
  "data": {
    "delivery_charge": 1.250
  }
}
```

<ParamTable
  title="data fields"
  params={[
    { name: 'delivery_charge', type: 'number', required: true, description: 'The quoted delivery fee for this route, in the branch\'s configured currency.' },
  ]}
/>

:::caution A quote is not a reservation
The charge is computed on demand from current configuration. It is not held, and creating the order
later recomputes it. Treat the value as an estimate to display, not as a locked price.
:::

## Not in the published Postman collection

This endpoint is routed and live in the backend but has **no entry in the published Postman
collection**. It is documented here from the implementation. See the
[coverage audit](/coverage#in-backend-not-in-postman).
