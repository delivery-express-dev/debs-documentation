# Create Order (Service)

<Endpoint method="POST" path="/api/v1/internal/orders" auth="X-API-Key header" />

Creates one order on behalf of an integration. Unlike the partner API this takes a single order, not
a batch, and names the fulfilling branch explicitly.

It is **safe to retry**: `integrationOrderId` is unique per order, and a repeat submission returns
`409` carrying the id of the order that already exists — so a caller that lost its response can
recover the order id instead of creating a duplicate.

<TabItem value="python" label="Python">

```python
import os
import uuid
import requests

integration_order_id = str(uuid.uuid4())

response = requests.post(
    "https://sandboxapi.allowmena.com/api/v1/internal/orders",
    headers={
        "X-API-Key": os.environ["ALLOW_SERVICE_KEY"],
        "X-Correlation-ID": str(uuid.uuid4()),
        "Content-Type": "application/json",
    },
    json={
        "orderSource": 2,
        "orderType": 1,
        "supplierBranchId": 7,
        "amount": "12.500",
        "paymentType": 1,
        "referenceId": "SHOP-1001",
        "integrationOrderId": integration_order_id,
        "customerDetails": {"firstName": "Sara", "lastName": "Al-Ali"},
        "dropOffDetails": {"location": {"latitude": 29.3759, "longitude": 47.9774}},
    },
    timeout=30,
)

if response.status_code == 409:
    # Already created by an earlier attempt — recover the id instead of retrying.
    order_id = response.json()["detail"]["orderId"]
else:
    response.raise_for_status()
    order_id = response.json()["data"]["orderId"]

print(order_id)
```

### Recovering from a 409

```json
{
  "status": false,
  "status_code": 409,
  "error_code": "CONFLICT",
  "message": "An order already exists for this integrationOrderId.",
  "detail": {
    "orderId": 19444,
    "integrationOrderId": "11111111-2222-3333-4444-555555555555"
  }
}
```

Read `detail.orderId` and carry on — the order exists and is live. Do not generate a new
`integrationOrderId` and retry, which would create a genuine duplicate.
